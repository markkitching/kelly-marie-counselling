# Images

Place your photos here. The site references two images:

| Filename | Used in | Recommended size |
|---|---|---|
| `kelly-hero.jpg` | Hero section (right column portrait) | 600 × 800 px minimum, portrait orientation |
| `kelly-about.jpg` | About section (left column square photo) | 800 × 800 px minimum, square crop works best |

Both images degrade gracefully — if a file is missing the site displays a styled placeholder, so the page will always look good even before photos are added.

**Tips:**
- JPEG or WebP both work. Compress to ≤ 200 KB for fast page load (use [Squoosh](https://squoosh.app) or [TinyJPEG](https://tinyjpeg.com)).
- Ensure you own the rights to any photo used on the site.
- Face should be well-lit, background neutral or soft — the warm stone and sage tones of the site complement natural, outdoor-inspired backgrounds well.
